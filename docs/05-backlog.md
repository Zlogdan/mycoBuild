# Бэклог (следующие доработки)

## 1. Pattern Infuser
Переопределение паттерна экземпляра чужим паттерном (`UpgradeInstance.overriddenPatternID` →
`Upgrade.GetPattern` берёт паттерн другого мода). В сохранении игрока 15 таких экземпляров.
- Разобрать в IL окно `PatternInfuserWindow` и правила (что можно вливать, ограничения по редкости/размеру).
- В редакторе: у размещённого мода выбор «паттерн от мода X»; в формате билда — поле `patternFrom`.
- При импорте из сохранения — учитывать `overriddenPatternID`.

## 2. Выбор стихии у модов
У ряда модов стихия задаётся экземпляром/свойством (например, `UpgradeProperty_Damage.effectType`,
призмы, «Призма фокуса»), и это важно для билдов. По аналогии с полем «Расширение» у «Нарушения границ»:
- найти в данных и коде, какие моды позволяют выбрать/получают случайную стихию и откуда она берётся (сид?);
- поле «Стихия» у размещённого мода, учёт в формате билда, импорт из сохранения (из сида, если так в игре).

## 3. Явные характеристики и сводка билда
- Вычислять конкретные значения характеристик экземпляра из `Seed` (порт `Upgrade.ModifyPropertySeed`,
  масштабирование от размера паттерна `Modify*FromPatternSize`, стаки).
- Суммарное отображение характеристик всех модов билда.

## 4. «Демонстрация билда»
Отдельная кнопка → режим/страница для скриншота: только сетка с паттернами (без интерфейса), список модов
и их параметры (если есть), название снаряжения, уровни. Оформление под соцсети/чаты.
