# Бэклог (следующие доработки)

## 1. Pattern Infuser — ✅ сделано
Экземпляр мода может использовать паттерн другого мода (`UpgradeInstance.overriddenPatternID`).
Правила из IL (`PatternInfuserWindow`): донор — другой мод того же снаряжения и той же редкости
(Contraband нельзя), в игре донор сгорает. Характеристики, помеченные в `Apply` вызовами
`Modify*FromPatternSize` / `GetPatternSizeRatio`, масштабируются множителем
`GetPatternSizeRatio(текущий, родной)`: меньше → (1 + r) / 2, больше → 0.85·r + 0.15 (не выше 1 + Δ/7.5 и 2).
Экстрактор помечает такие моды флагом `patternScaled` (646 из 764; у остальных смена паттерна без потерь).
- Карточка мода: выбор «Паттерн» (свой или любого донора, вручную можно и больше), множитель характеристик.
- Формат билда: `placed[].patternFrom`; неверный донор → предупреждение `badInfusion`.
- Импорт сохранения: `overriddenPatternID` → `patternFrom`, клетки проверяются игровой формулой.
- Автоподбор, блок «Pattern Infuser»: «Разрешить» (только такие же или меньшие паттерны и только если это
  помогает разместить больше), «Только моды без потери свойств» (меньший паттерн — лишь модам без
  `patternScaled`, остальным — только того же размера), «Принудительно экономить место» (минимизировать
  занятую площадь, даже если всё помещается). Вторичная цель солвера — штрафы (< 1 в сумме), плюс нижняя
  оценка числа нужных вливаний и локальная «полировка» решений.

## 2. Выбор стихии у модов — ✅ сделано
- Источник: `UpgradeProperty.GetRandomEffect*` (код игры). У экземпляра нет поля стихии — она выпадает из
  `Random` свойства (`Upgrade.ModifyPropertySeed(seed, i)`); набор вариантов задаёт вызываемая функция
  (огонь/шок/кислота, + обычная, + крио, + пчёлы). Свойство с собственным ненулевым `element` — фиксированная стихия.
- 58 модов с выбором (`Upgrade.elementChoice`); поле «Стихия» у размещённого мода, метка на сетке, формат билда
  (`placed[].element`), фильтры стихий учитывают выбор.
- Правила броска извлекаются из IL (`statmap.build_element_rules`): условие случайности (например, `effect == All (127)`
  у `MycoGear_GrabDamage`, `element == 0` у `PhotonDisc_Attunement`) и броски `Random` до выбора стихии
  (`OverrideData.ApplyTo`/`Range.GetValue` на том же генераторе; поле с `method = None` не бросает).
- Импорт из сохранения: стихия вычисляется из сида для всех 55 модов (`Upgrade.elementRoll`).
- `EffectType.All (127)` — «Универсальные (любая стихия)»: моды, работающие с любой стихией.
- Названия стихий — ключи `el_*` (ключи `fire`/`shock`… — словари синонимов для подсветки).
- Исправлен порядок свойств мода (как в `Upgrade.properties`) — важно для сидов.

сетка в игровом стиле (`StaticBoard`), моды с редкостью, стихией экземпляра и характеристиками (переключатели
